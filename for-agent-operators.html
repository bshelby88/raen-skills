The fix is a sweep, not a dashboard

The Steward Pattern ($29, one-time) is the operating procedure a live 12-service x402 payments fleet on Base has run on a 4-hour cron since November 2026. Every pass, in order:

  1. Liveness — /health on every service, with the local-DNS false-negative check before you ever "restart" anything.
  2. Drift — payment-manifest invariants verified against a live 402 challenge decode, not just the file (manifests lie; a stale payTo silently misroutes money).
  3. On-chain truth — balances and ledger scans over plain public RPCs, no explorer API key, with phantom-revenue detection (telemetry says $6; chain says $0.10 — here's why that happens).
  4. Verify the fix, not the intent — secrets set doesn't refresh a running machine; a "Ready" Vercel deploy can 404 on every path; scale-downs can stop a Postgres primary. Each has a tested recovery.
  5. Proof of liveness — one run artifact per pass, so silence is evidence, not anxiety.
