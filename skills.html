Install into Claude Code (free preview, then pay)

Grab the free-form skill files and drop them in your project's skills directory. Read them first — then pay for the maintained versions with the full run logs, incident post-mortems, and update access.

mkdir -p .claude/skills && cd .claude/skills
for s in steward-pattern-flyio charge-and-rebate-funnel x402-production-deployment; do
  curl -sL "https://raw.githubusercontent.com/bshelby88/raen-skills/main/skills/$s/SKILL.md" -o /dev/null -w "%{http_code} $s\n"
done

To install one for real:

mkdir -p .claude/skills/steward-pattern-flyio
curl -sL "https://raw.githubusercontent.com/bshelby88/raen-skills/main/skills/steward-pattern-flyio/SKILL.md" \
  -o .claude/skills/steward-pattern-flyio/SKILL.md

Claude Code picks it up on the next session; when a task matches the skill's description, it loads automatically. No plugins, no build step.

Why skills beat docs

  • Progressive disclosure: the agent reads the description first, loads the full procedure only when relevant — context stays small.
  • Command-level detail: exact curl/flyctl/gh commands with the flags that actually work (MSYS path quirks, Fly token gotchas, Vercel 404-after-ready traps).
  • Written by the system that runs them: every rule came from a real incident on our fleet, not from documentation.
